# 查找、阅读与学习画布：交互提案

状态：用户已认可查找、预览、对照学习，以及独立学习画布的方向。以下交互细节作为实现前提案，不代表功能已实现；正式 UX-CONTRACT 在实现与真实材料验证后更新。

## 已确认的画布方向

- OnePKU 侧栏提供独立“画布”栏目，用户可以先打开画布，再搜索材料并放入。
- 搜索与画布结合：命中的讲义页、回放时间点、图片与笔记可以成为画布内容。
- 保留 Excalidraw 的链接内嵌能力，不把画布限定为学校材料。
- 明确标注“基于 Excalidraw”，保留开源项目归属。
- 优先沿用 Excalidraw 已有的嵌入和对象交互，先核对上游行为，再补 OnePKU 的材料接入；不预设另一套选择、激活或拖动规则。
- 下文中的列表形态、快捷键细节、卡片交互与状态规则是具体设计建议。

## 目标

让用户找到具体内容、在合适的尺寸下阅读，并能回到刚才的学习位置。一次操作应当能回答：我打开了什么、在哪里、如何回去。

围绕三个真实已有对象设计：课程资料、课程回放、作业说明。沿用 OnePKU 的单一主内容区和现有课程导航；对照阅读由用户主动进入。画布作为独立学习入口，在主内容区打开，允许跨课程和外部链接组织一个专题。

## 四种状态

1. 查找：一个临时搜索浮层，结果提供足够的命中上下文。
2. 单独阅读：主内容区打开文件、作业详情或回放中的具体位置。
3. 对照阅读：同一学习区域并排放回放和用户选定的讲义。
4. 画布：自由摆放材料、绘图和笔记；从当前画布打开搜索，把结果放到画布上。

搜索负责寻找与选择，在普通页面中打开目标，在画布中放入材料。阅读使用足够大的主区域。对照模式只保留两个内容区域，笔记编辑按需出现；画布布局由用户自由组织。

## 画布栏目

### 入口与列表

- 学习分组增加“画布”，与课程、作业等入口同级；侧栏名称只用“画布”。
- 栏目首页展示已有画布：缩略图、名称、最近编辑时间；默认按最近编辑排序，提供搜索名称和“新建画布”。不先要求创建文件夹、选课程或模板。
- 新建立即进入空白画布，默认“未命名画布”，标题可直接修改。一个画布可包含多个课程的材料，不强制绑定某门课程。
- 空白状态给出两个就地动作：“搜索材料”和“粘贴链接”，开始编辑后收起引导。
- 列表页底部及编辑页帮助菜单显示“基于 Excalidraw”，链接到项目主页；关于页保留第三方许可。产品主标题仍为 OnePKU 的“画布”。

### 编辑区域

- 打开画布后使用完整主内容区；侧栏可收起，沿用用户选择，不因每次打开画布反复改变。
- 顶栏保留返回画布列表、名称、保存状态和“搜索材料”；链接插入、导出等收在工具栏或更多菜单。
- 保留自由平移、缩放、形状、文字、箭头、自由绘制、图片和链接嵌入。不沿用 AIOJ 固定纸张框及禁用图片工具的限制。
- 返回列表保存当前画布并恢复原列表位置；再次打开恢复视口、缩放、材料位置与大小。打开原资料后返回也恢复同一画布视口。

### 从搜索放入材料

- 在画布内按 Cmd+K 或点“搜索材料”，打开主区域右侧的临时搜索面板。保留可见画布，面板宽度不能挤到只能看见一条画布；窄窗口改为浮层并提供按钮放入。
- 搜索默认跨课程，可选择课程、学期和材料类型。复用全局搜索索引、来源身份、版本与命中范围。
- 结果行点击选中并展开命中预览；“放入画布”是主要动作，“打开原文”是独立动作。选择结果不自动离开画布，也不启动播放。
- 可以把结果拖到可见画布位置；按钮或结果焦点下 Enter 放到当前视口内的空位，选中新对象但不突然缩放整张画布。输入框 Enter 先选中结果，不因提交关键词意外连续添加。
- 放入后保留关键词、筛选和结果滚动位置，可以连续取材料；Escape 先收起预览，再关闭搜索并把焦点还给画布。
- 加入动作不自动去重或跳到旧卡片；允许同一来源被用于不同推导。每次成功加入有轻量反馈，并支持撤销。

### 材料的形态与原文

| 材料 | 放入内容 | 就地操作与来源 |
| --- | --- | --- |
| PDF 命中 | 命中的具体页，或用户明确选择的摘录 | 显示文件名、页码；可放大阅读，打开原讲义定位该页；不默认放入整本 PDF |
| 回放字幕命中 | 对应回放及命中时间点的视频卡片 | 暂停等待播放，保留命中短句；可在画布播放、全屏、打开原回放；没有可靠片段边界时只标时间点 |
| 图片或截图 | 图片本身 | 缩放、批注；已有课程来源的图片保留来源入口 |
| 已有笔记 | 笔记的当前内容副本与原笔记链接 | 在画布中编辑该副本；需要改原笔记时明确打开原笔记，不隐式双向改写 |
| 作业说明或通知 | 命中片段及标题 | 打开原文；画布内容不承担作业提交或学校记录修改 |
| 普通网页或视频链接 | 原版嵌入能力支持的网页内容 | 保留来源地址与“在浏览器打开”；被源网站禁止嵌入时保留链接卡片 |

- 可阅读和播放的卡片沿用 Excalidraw 原生嵌入对象的选择、拖动、缩放及激活逻辑。上游已有悬停“点击以交互”提示与激活后接收鼠标事件的机制；不额外强制标题条拖动或自建激活按钮。PDF 和课程播放器接入同一容器后，验证内容滚动、画布平移、退出激活与键盘焦点；只有确认原有机制无法满足真实操作时再定向调整。
- 开始播放一张卡片时暂停同一学习区域其他播放器。打开搜索不打断当前播放；离开画布暂停；回来或重启后只恢复位置，不自动出声。
- 全屏媒体退出后回到原卡片和原画布视口。放大阅读可使用临时阅读层，关闭后保留原布局。
- 删除卡片只移除当前画布中的对象；原文件、回放与原笔记仍由各自原入口管理。

### 外部链接内嵌

- 保留“嵌入网页”工具；粘贴有效 HTTP(S) 链接后可选择“内嵌”或“普通链接”。普通文字仍按文字处理。
- 第三方内容在无本地命令、文件与学校会话权限的隔离容器中加载；不向链接站点转发 OnePKU 凭据。学校资料与回放通过应用已有的授权读取链路呈现，来源引用不存临时访问令牌。
- 明确反馈加载中、无法嵌入与需要登录。无法嵌入时提供“在浏览器打开”，不绕过网站的嵌入限制，也不让一张失败卡片阻塞整个画布。
- 此处是对当前“普通外链使用系统浏览器”的显式产品扩展；普通外链点击规则保持原样，只有用户选择内嵌时进入画布容器。具体 WebView 能力需实测，不能把 React 编辑器接入视为外部网页播放已通过。

### 保存与恢复

- 画布自动保存到本机持久存储，内容包含绘图场景、学习材料引用、来源版本、摘录及必要预览、视口和卡片阅读位置。用户可见状态为“保存中 / 已保存 / 保存失败”，失败保留编辑并可重试。
- 已归档文件与回放缓存沿用现有资源管理；每次放入不会复制整份视频。材料缺失时保留卡片位置、标题、笔记和现有预览，提供重新获取来源的操作。
- 材料来源更新不悄悄替换用户批注所依附的旧页或摘录；提示有新版本，由用户打开核对后决定替换。
- 画布按当前账号归档。切换账号停止播放并隐藏上一账号内容，返回原账号可恢复；认证过期不删除用户本地创作，重新获取学校内容仍需有效权限。
- OnePKU 完整画布导出需同时保留课程来源与卡片信息；若另外提供标准 Excalidraw 导出，应说明哪些学习卡片会变成静态内容，不能把可播放、可定位能力算作普通场景文件天然具备。

## 搜索到具体内容

### 入口与范围

- 应用侧栏顶部提供“查找”，Cmd+K 打开同一入口。
- 默认跨课程搜索，允许通过一个范围选择器限定当前课程。
- 保留当前关键词、范围、选中结果和结果列表滚动位置。关闭浮层不改变底下的页面和播放位置。
- 中文输入法完成输入后再查询；查询较慢时保留上一批结果，但明确标记正在更新，旧结果不得冒充新词结果。

### 一条结果的最少信息

标题、课程与学期、命中片段、定位信息。PDF 的定位为页码，字幕为回放日期与时间点，通知和作业为正文片段。

没有可靠的页码或时间点时只显示可验证的文件或对象，不制造精确定位。字幕结果明确已识别的覆盖范围，部分字幕无命中不等于整节未讲过。

### 点击规则

以下规则适用于普通全局搜索；画布内搜索使用上文的“预览 / 放入画布 / 打开原文”动作。

| 点击的结果 | 打开位置 | 结果上下文 |
| --- | --- | --- |
| 课件内容 | 当前主区域的文件阅读器，定位对应页并突出命中 | 顶部“返回搜索”恢复原查询与选中项 |
| 回放字幕 | 对应回放与时间点 | 同一视频保持原播放/暂停状态；另一视频定位后保持暂停，用户点播放 |
| 作业说明 | 现有作业详情，定位命中段落 | 保留课程与作业标题、提交状态 |
| 课程通知 | 对应原文窗口或已验证的正文位置 | 无法可靠定位原文时打开原文顶部并告知未定位 |

搜索结果默认打开一个完整的目标，不先跳到课程首页让用户再找一次。

打开文件或另一条回放时保存并暂停旧回放。返回旧回放恢复原时间点，保持暂停，避免突然出声。只打开或关闭搜索浮层不暂停当前回放。

### 导航与键盘

- 搜索输入框自动获得焦点；上下键选择结果，Enter 打开，Escape 关闭。
- 关闭搜索时恢复触发位置的焦点；从结果阅读返回搜索时恢复结果选中项。
- 内容标题下显示真实课程归属。顶栏“返回搜索”和课程归属各有明确含义；应用后退与可见返回按钮遵守同一条访问历史。
- 文件不存在、未下载或来源版本变化时，在原结果位置说明原因并提供取得文件或重新搜索的动作，不跳到空白阅读器。

## 文件预览就是完整阅读

从课程资料、作业附件、搜索结果打开同一个文件阅读器，返回目的地由实际来路决定。

顶栏只保留：返回、文件标题、PDF 页码与缩放、用系统应用打开，以及“对照回放”。收藏、来源和其他操作收在更多菜单。

先覆盖真实课程中常用的 PDF、图片、纯文本；其他格式保留系统应用打开。课件预览首次需要取文件时，只取用户选中的文件并显示进度；取消离开可停止请求。

PDF 默认适合宽度，可输入页码，记住同一版本文件的页码和缩放。来自搜索的定位优先于上次阅读位置。新版本不得机械沿用旧版页码作为命中位置。

预览关闭后返回原课程资料、原作业或原搜索结果，保留它们的筛选和滚动位置。

## 回放与讲义对照

### 主动进入

- 回放里点“对照讲义”，从当前课程的资料选择讲义；选择完成后并排显示，回放继续原来的播放状态。
- 讲义里点“对照回放”，选择当前课程的课次；新视频保持暂停，由用户开始播放。
- 记住这一课程上次使用的回放与讲义组合，只作为默认候选，允许更换。不得以相近日期推定这份 PDF 必定对应此课次。

### 布局

宽窗口默认左回放、右讲义，初始接近一半一半，中间可拖动。两边顶栏分别写清当前课次和文件名，两侧各自滚动。回放和讲义不假定自动同步。

进入对照时收起应用侧栏，为内容让出宽度；退出时恢复原来的侧栏状态。课程标题与返回仍可见。

使用实际可用内容宽度判断能否并排：初始设计要求视频至少约 420 px、讲义至少约 480 px，具体阈值在真实 PDF 阅读验证后确定。

不足以并排时使用“回放 / 讲义”切换主视图，不把讲义压成窄条。切换保留双方位置；讲义为主时，若视频仍在播放，保留一条带课次、时间和暂停按钮的紧凑播放条。

### 全屏与退出

- 回放全屏只展示视频与可自动收起的控制栏；退出恢复原讲义、页码和分栏比例。
- 讲义可临时独占阅读区；返回恢复原对照状态。
- 关闭讲义一侧回到单独回放，继续当前状态；离开整个对照区域时保存双方位置并暂停回放。
- 全屏 Escape 优先退出全屏；非全屏 Escape 只关闭当前临时浮层，不突然离开学习区域。

### 笔记

“记一下”打开短编辑浮层，默认附上当前视频时间或 PDF 页码。来源由触发位置决定；对照状态提供明确的来源选择，不假定两侧内容相关。

保存后回到内容，笔记可跳回来源。完整笔记列表按需打开，并替换讲义辅助区，避免同时堆叠视频、PDF、搜索与笔记四块区域。

## 状态保存

- 搜索会话：查询、范围、选中项、滚动位置与打开前的页面。
- 文件阅读：课程、文件身份与版本、页码、缩放。
- 回放：课程、回放身份、时间、播放/暂停、倍速。
- 对照：两个内容对象、当前主视图、分栏比例，以及进入前的应用侧栏状态。
- 画布：场景、材料来源与版本、视口、阅读位置；画布内搜索会话和原文返回位置。
- 账号切换清除当前私有上下文；不同课程、不同学期、不同来源版本不串用位置。

短暂浮层的状态在当前浏览会话内保留；文件和回放的阅读位置跨重启保留。关闭应用后重开恢复位置，不自动开始播放。

## 与现有实现的关系

### Excalidraw 上游能力核对

2026-09-10 核对官方文档与上游提交 `6574de60b3fae9a645023ef2743d8213f6df1bda`，以下为源码证据，尚未代表 OnePKU WebView 运行验证：

- 原生支持图片文件插入，以及网页嵌入对象；YouTube、Vimeo 等链接有专门的嵌入地址转换和视频处理。
- `App.tsx` 的 `handleIframeLikeElementHover`、`handleIframeLikeCenterClick` 和 `renderEmbeddables` 已有悬停提示、点击激活与基于 active 状态分配鼠标事件的处理。基础对象交互直接复用。
- 本次核对的开源编辑器文件拖入链路处理图片与 Excalidraw 场景/素材库；没有提供将本地 PDF、MP4 当作独立文件直接阅读/播放的完整内置导入链路。不能把网页嵌入等同于通用本地文件阅读器，也不能据此推断 Plus 的全部能力。
- 官方 `renderEmbeddable(element, appState)` 允许替换默认 iframe 内容，`customData` 可记录来源引用。因此优先用原有嵌入对象承载 OnePKU 的 PDF 阅读器与课程播放器；普通外部网页继续使用原生嵌入。搜索、来源定位、授权取文件与持久保存由 OnePKU 接上。
- 实现前选定实际依赖版本并复核其行为，不直接把上游 master 当作已发布版本。当前 AIOJ 的 `0.18.1` 也不自动代表 OnePKU 的依赖选择。

参考：[官方嵌入扩展接口](https://docs.excalidraw.com/docs/@excalidraw/excalidraw/api/props/)、[嵌入交互源码](https://github.com/excalidraw/excalidraw/blob/6574de60b3fae9a645023ef2743d8213f6df1bda/packages/excalidraw/components/App.tsx)、[嵌入链接处理](https://github.com/excalidraw/excalidraw/blob/6574de60b3fae9a645023ef2743d8213f6df1bda/packages/element/src/embeddable.ts)。

### OnePKU 阅读状态

当前 Courses.tsx 按资料/回放页签条件渲染，切换会卸载 Videos 和播放器；播放对象还只保存在 Videos 局部状态。App.tsx 跨主页面导航会重置主区域滚动。

落实本提案需要让课程的阅读状态拥有回放对象、文件对象和对照状态，并让明确的目标定位与返回恢复优先于普通导航的滚动重置。搜索结果必须引用相同的课程、文件版本和回放身份，不能另造一套预览对象。

第一轮不依赖课件与视频的自动语义对齐。结构化搜索先提供可靠目标，字幕识别范围与 PDF 可提取范围独立呈现。

## 评审与验收旅程

1. 从真实课件复制一个短语搜索 → 打开命中页 → 返回搜索 → 选中另一项；关键词、列表位置和结果选择没有丢失。
2. 从一节已有字幕的回放搜索实际句子 → 跳到来源时间点；未生成部分明确标记，不伪称检索了整节。
3. 看回放 → 打开本课讲义对照 → 翻页 → 视频全屏 → Escape → 回到原分栏、原页码和原时间。
4. 把窗口缩到现有最小尺寸 → 在讲义与回放间切换，仍可读、可暂停，两个位置都保留。
5. 在视频时间点记一句话 → 离开课程 → 从笔记返回该位置；笔记来自 PDF 时同样回到对应页。
6. 选择未下载文件后取消、遇到读取失败、遇到新版本，均能回到原来的查找或阅读位置。

7. 从画布栏目新建专题 → 搜索真实讲义短语 → 预览并放入命中页 → 继续搜索真实回放字幕 → 放入对应视频卡片；画布、关键词与结果位置不中断。
8. 在卡片间批注连线 → 操作 PDF / 视频 → 退出交互继续移动卡片；滚动、播放与画布拖动不争抢手势。
9. 放入一个真实可嵌入外链及一个禁止嵌入的外链；分别验证内容交互和浏览器打开回退，其余画布仍可编辑。
10. 离开画布、重启、重新打开 → 布局、批注和阅读位置恢复且不自动播放；遇到来源不可用、版本更新、保存失败时保留已有工作。
11. 从画布打开原讲义页或回放时间点，再后退，回到同一画布位置；账号切换后不显示上一账号材料。
12. 画布列表与帮助入口可看到“基于 Excalidraw”，项目链接正确；第三方许可随应用分发保留。

先用本人的真实 PDF、回放与网页走通以上操作，再将行为写入正式 UX-CONTRACT。当前文档记录已接受方向；搜索首版正在本机实现，其余画布与对照旅程尚未验收。


### 搜索首版本机实现（2026-09-10）

- 全局搜索入口与 ⌘K；多个搜索标签保留关键词、筛选和选择；左侧结果、右侧单项大预览。
- 本学期优先，可选择全部学期。检索课程、资料说明/附件名、回放标题、作业与通知正文，以及本机 PDF 可提取文字。逐项显示已读取内容，失败来源可展开核对。
- PDF 命中保留课程、文件修订 ID、物理页码；预览一次只显示一页。画布对象以后也以单页呈现，复制对象后独立翻页，即可把不同页并排放置。复制不另存原 PDF。
- 本机 PDF 限 32 MB、前 400 页；无可提取文字的文件按文件名检索。回放字幕检索、画布放入/复制、跨重启搜索会话恢复仍待实现。


本轮验证：49 项前端测试通过；Rust 资料身份/跨课程/文件变更/链接校验的 3 项现有测试通过。Chrome 和原生 WKWebView 均验证真实讲义“巴拿赫”命中物理第 42、43 页，原生已读取 10 份 PDF。修正中文 CMap 随包分发与本地加载、WKWebView 不支持流异步迭代的问题。原生验证单页翻页、切换搜索标签保留第 2 页、⌘K 关闭/重开保留关键词。

最终本机安装包已更新，原生 PDF 读取及重启后全文命中已验证。画布与复制并排没有在这一轮实现。

### 搜索延迟与重启恢复（2026-09-10）

索引保存在本机 IndexedDB，以教学网会话 generation 隔离；应用启动时预读，搜索框打开后直接检索已有内容。后台重新核对本地文件修订 ID，仅解析新增或变化的 PDF；删除或替换的修订及其页命中一并移除。元数据复用五分钟内的缓存；手动刷新不重复解析未变化的文件。切换学期范围不会清空已有索引。

本轮 55 项前端测试通过，包含学校 API 尚未返回时即可命中缓存正文、启动预读、未变化 PDF 不再读取、修订变更和旧页删除、账号缓存作用域。应用构建通过并安装至本机。

真实数据验证：10 份 PDF、445 项索引内容。浏览器重载后“巴拿赫”命中第 42、43 页，网络记录仅有右侧预览的一次文件读取，没有批量重解析。四次查询“巴拿赫 / 概率 / 计算机系统 / Lab”从输入到结果提交后的绘制帧分别为 39.6 / 37.2 / 28.6 / 35.3 ms（本机内置 Chromium，1280×720，真实后端；不代表原生 WKWebView 延迟统计，不包含 PDF 预览完成时间）。原生另行验证建立索引后退出、重新启动，已有 445 项恢复。无应用控制台错误；原 PDF 字体 TT 警告未阻碍正文提取与显示。

首次索引和新文件仍需读取；预览有独立加载耗时。跨重启恢复的是索引，搜索标签仍只在本次启动内保留。尚无 OCR、回放字幕全文或语义检索。
